Package publication

Register once.
Tag every release.

silex register opens the package's single registry proposal. Package owners publish every version directly with Git tags.

  1. 01

    Prepare the package

    Set the semantic version and Silex compatibility range, then commit the complete package contents.

  2. 02

    Check optionally

    Run silex check path/to/Package for a read-only validation of the package contract and expected version tag.

  3. 03

    Register once

    Run silex register path/to/Package once. Silex creates or reuses your fork and submits the package name with its canonical repository. No release metadata is copied into the registry.

  4. 04

    Tag every version

    Create and push the matching vMAJOR.MINOR.PATCH tag with Git. Silex discovers it without another registry pull request.

$ Publish Example 1.0.0 
$ silex check Packages/Example
silex: package Example@1.0.0 is valid;
its release tag is v1.0.0

$ silex register Packages/Example

silex: submitted registration of Example
for registry review at
https://github.com/Matanek/
Silex-Registry/pull/123

$ git tag v1.0.0
$ git push origin v1.0.0
