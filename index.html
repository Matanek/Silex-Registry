Package publication

One release.
One command.

silex publish verifies the tagged archive and its checksum, then prepares the immutable registry manifest. A pull request keeps every publication reviewable before installation.

  1. 01

    Tag the package

    Set the semantic version and Silex compatibility range, then publish the complete package from that exact commit.

  2. 02

    Publish the archive

    Create an immutable release archive and calculate its lowercase SHA-256 checksum.

  3. 03

    Prepare the publication

    Run silex publish path/to/Package from a checkout containing Silex-Registry. Silex verifies the release and writes the version manifest.

  4. 04

    Open a pull request

    Review the prepared manifest and let the registry checks validate the complete index. Existing releases remain immutable.
